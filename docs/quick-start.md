# Quick start

This tutorial follows a first method-generation run. Complete the installation checks and use a database validated for your sample and experiment.

## 1. Check the environment

Open [Environment Check](environment-check.md), select the interpreter and run the checks.

## 2. Prepare a database

If a suitable database is already available, select it on Main. Otherwise follow [Database Generator](database-generator.md). See [Input files](input-files.md) for the schema information that needs to accompany the release.

## 3. Configure and start

On [Main](main.md), choose the database and output directory. Set the run identifier, TMT plex, duration, AIDA+ state and Full/Light caller. Review [Advanced](advanced.md) settings as needed, then click Start.
