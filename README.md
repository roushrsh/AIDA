# AIDA documentation project

Editable Sphinx documentation using Markdown and the Read the Docs theme.
This package contains documentation, not the AIDA software or runnable example datasets.

## Start here

1. Open `preview/index.html` to browse the included HTML preview. If local search is blocked by your browser, serve the preview using `python -m http.server --directory preview 8000` and visit `http://localhost:8000`.
2. Edit the `.md` files in `docs/`. Start with `docs/index.md` and the page for each tab.
3. Search the source files for `AUTHOR TODO` and complete those fields. They mark details that cannot be verified from screenshots.
4. Follow `SETUP.md` to build and publish on Read the Docs.

The preview is a snapshot. Editing Markdown changes the website only after rebuilding.
The screenshots come from the author-supplied RoughAIDA.pdf. Visible defaults illustrate that capture and do not establish validated recommendations.

## Included pages

Introduction, installation, quick start, all nine GUI tabs, input formats, outputs, paper workflow, troubleshooting, citation and an author editing guide.
