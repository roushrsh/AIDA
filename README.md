# AIDA
AI Driven Acquisition


AIDA is a software method for real-time data acquisition of tribrid mass spectrometers.

Installation:

AIDA Can just be extracted from the zip file in this github. The larger .exe application file with the AIDA icon has to be double clicked for it to open to this image
